# Sessions tools/telemetry/dashboard.mjs leaves out of every report (#364).
#
# One session id per line — the code Settings → Privacy shows, or its first
# eight characters as the report prints them. For sessions that are not play
# at all: a debugging session, a bot, a run of deliberate deaths to test the
# game-over screen. Everything after a # is a comment.
#
# Somebody who simply knows the game well — the maintainer playing normally —
# does not belong here. Their runs are real runs. Name them in
# known-sessions.txt instead and the report shows them beside everyone else's.
#
# Runs from `npm run dev` (a build id ending in -dev) are left out without
# being listed here.
